Portfolio and Learning Log of Varshini Gayathri Suresh: https://vgs1004.github.io

## Add a new Learning Log post

1. Open the `_posts` folder, click **Add file**, then **Create new file**.
2. Name it `YYYY-MM-DD-learning-log-NN-short-title.md`, for example `2026-11-14-learning-log-02-dax-basics.md`.
3. Paste this at the top, then write the post in plain Markdown below it:

```
---
layout: post
title: "Your post title"
series: "Learning Log #2"
summary: "One or two sentences shown in the post list."
date: 2026-11-14 00:00:00 +0100
image: /files/log-02-cover.png   # optional: a cover image, also good for the LinkedIn post
---
```

4. Click **Commit changes**. The site updates in about a minute. The post appears in the Learning Log section of the home page, newest first, and also gets its own link for sharing on LinkedIn.

## Add images or PDFs

1. Open the `files` folder, click **Add file**, then **Upload files**, and drop in your images or PDFs.
2. Use simple names without spaces, for example `log-01-cover.png` or `dax-notes.pdf`.
3. Click **Commit changes**. Then add `image: /files/log-01-cover.png` to the post's top block, or link a PDF in the post as `[DAX notes (PDF)](/files/dax-notes.pdf)`.
